# Trackify by Kominal – Time Tracking made simple

[![GitHub License](https://img.shields.io/github/license/kominal/trackify?style=flat-square)](https://github.com/kominal/trackify/blob/production/LICENSE.md)
![Deployment](https://img.shields.io/github/actions/workflow/status/kominal/trackify/deployment.yml?style=flat-square)
![Technologie TypeScript](https://img.shields.io/badge/TypeScript-blue?style=flat-square)

![Screenshot of the Trackify dashboard](docs/images/banner.png 'Trackify dashboard')

Track time on tasks with one click, see where it went, and compare it with what you actually did on your PC.

- **Web app** at [trackify.kominal.cloud](https://trackify.kominal.cloud): tracking, entries, clients/projects/tasks, and a dashboard with a timeline, hours per day and breakdowns by project and application.
- **Desktop app for Windows** ([download](https://github.com/kominal/trackify/releases/latest)):
  - starts with Windows and lives in the tray;
  - reminds you when the tracked task has not changed for a while, or when nothing is tracked while you work;
  - records which window is in focus, so untracked time shows up on the dashboard and can be booked with one click.
  - Window activity is visible only to you and deleted after 180 days.
